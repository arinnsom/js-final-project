#  Интернет-магазин светильников Briaton (Финальный проект по модулю JavaScript)

Динамическое многофункциональное веб-приложение интернет-магазина, реализованное на JavaScript. Проект демонстрирует навыки управления состоянием интерфейса (UI State), динамической подгрузки данных и реализации логики каталога электронной коммерции.

##  Демо-версия проекта
[https://arinnsom.github.io/js-final-project/](https://arinnsom.github.io/js-final-project/)

---

##  Используемый стек технологий
* **JavaScript (ES6+)** — разработка всей логики приложения, динамический рендеринг, фильтрация и стейт корзины
* **HTML5 / CSS3 / SCSS** — работа с готовой семантической разметкой и препрецессорными стилями UI-компонентов
* **DOM API / Event Handling** — манипуляция элементами страницы, переключение классов и делегирование событий

---

##  Реализованный функционал и архитектурные задачи

В ходе проекта была оживлена статическая верстка и решена задача связывания данных с интерфейсом посредством добавления/удаления CSS-классов состояний:

###  Динамический каталог и Данные
* **Mock-Server Data:** Настроена динамическая подгрузка и рендеринг карточек товаров на основе актуальных данных.
* **Фильтрация и Сортировка:** Реализована гибкая фильтрация товаров по типу светильников и наличию на складе, а также сортировка по популярности и цене (от дорогих к дешевым и наоборот).

###  Корзина и Интерактивные UI-компоненты
* **Модуль корзины:** Написана логика добавления товаров, пересчета их общего количества и суммарной стоимости в режиме реального времени.
* **Выбор города:** Интегрирована функция смены текущего региона пользователя с выбором доступных вариантов.
* **Аккордеон (FAQ):** Стилизован блок часто задаваемых вопросов, раскрывающийся по клику на элемент.
* **Слайдер:** Оживлен интерактивный слайдер для блока «Товары дня».
* **Форма обратной связи:** Настроена обработка отправки формы на консультацию с выводом кастомного всплывающего окна (Modal/Message) об успешной регистрации заявки.
